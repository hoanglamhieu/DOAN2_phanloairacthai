&nbsp;Đồ án phân loại rác thải sinh hoạt bằng CNN

&nbsp;Mô tả

Ứng dụng sử dụng Deep Learning (CNN) để phân loại rác thải.

&nbsp;Công nghệ sử dụng

\- Python

\- TensorFlow / Keras

\- Flask

\- HTML/CSS

&nbsp;Hướng dẫn chạy

1\. Cài đặt thư viện:

pip install -r requirements.txt



2\. Chạy:

python app.py
